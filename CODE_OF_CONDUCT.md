# Code of Conduct

We want this project to be practical, rigorous, and welcoming.

Participants are expected to:

- Be respectful and constructive.
- Assume good intent, but prioritize user safety and data protection.
- Avoid harassment, insults, or exclusionary behavior.
- Report security issues responsibly, following `SECURITY.md`.

## Scope

This applies in every project space - issues, pull requests, discussions, code
review, and commit messages - and when representing the project in public.

## Reporting

Report conduct concerns privately by email to security@contextdata.ai, which
the maintainers listed in [CODEOWNERS](.github/CODEOWNERS) read. Do not raise
them in a public thread.

Include what happened, where, and any links. You do not need to be certain a
rule was broken to report something that felt wrong.

Reports are handled privately. Reporters are not identified to the person
reported about without the reporter's agreement, except where the maintainers
are legally required to do so.

Do not use this channel for security vulnerabilities - those follow the private
disclosure process in `SECURITY.md`.

## Enforcement

Maintainers will review each report and respond in a way that fits the
situation. Possible responses, roughly in order:

1. A private correction explaining what was wrong.
2. A warning, with conditions on continued participation.
3. Removal of the offending comments, issues, or contributions.
4. A temporary or permanent ban from project spaces.

Maintainers who violate this code are subject to the same consequences, applied
by the other maintainers.
